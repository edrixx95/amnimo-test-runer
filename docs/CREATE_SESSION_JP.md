# 手順書 - 新規セッションの作成

テストの実行を開始するには、まず新しいセッションを作成する必要があります。

## 手順

1. ダッシュボード画面の右上にある **「新規セッション」** ボタン、またはセッションカード表示エリアにある追加ボタンをクリックします。
   > ![ダッシュボード画面](/images/manual/sessions/create-session/01-session-dashboard.png)

2. **「新規テストセッション」** というダイアログが表示されます。わかりやすい名前（例：`AG10-v3.8.0-release`）を入力し、**「セッションを作成」** をクリックします。
   > ![セッション作成ダイアログ](/images/manual/sessions/create-session/02-new-session-dialog.png)

3. 新しいセッションがリスト画面に表示され、画面は自動的にセットアップ画面に遷移します。
   > ![セットアップ画面](/images/manual/sessions/create-session/03-session-setup.png)

> [!NOTE]
> **注意事項:**
> ステップ3で（セットアップを完了せずに）退出した場合でも、作成したセッションは保存され、**ドラフト** タグが付いた状態でダッシュボードに表示されます。該当するセッションカード上の **設定** ボタンをクリックすれば、いつでもセットアップ画面に遷移してプロセスを再開できます。
> ![DRAFT セッション](/images/manual/sessions/create-session/04-session-draft.png)
